# Financial Analytics Dashboard

An end-to-end financial analytics platform built with **Python, Streamlit, Plotly, Scikit-Learn, and Google Gemini AI**.

The application allows users to upload financial datasets, analyze key financial indicators, visualize trends, forecast future revenue, and generate AI-powered financial insights.

---

## Project Overview

Financial Analytics Dashboard is designed to transform raw financial data into meaningful business insights through interactive analytics and machine learning.

The project demonstrates:

- Data ingestion and validation
- Exploratory financial analysis
- Interactive visualization
- Predictive modelling
- AI-assisted financial interpretation

The goal of this project is to create a professional analytics tool similar to dashboards used in financial and business intelligence environments.

---

# Features

## 1. Financial Dataset Upload

Users can upload CSV financial datasets directly through the dashboard.

Capabilities:

- Automatic dataset loading
- Data validation
- Missing value detection
- Data cleaning and preprocessing


## 2. Interactive Financial Dashboard

The dashboard provides:

- Revenue analysis
- Expenditure analysis
- Tax revenue tracking
- Debt monitoring
- Financial balance calculations

Key Performance Indicators:

- Total Revenue
- Total Expenditure
- Net Financial Balance
- Tax Revenue
- Outstanding Debt


## 3. Interactive Visual Analytics

Built using Plotly for dynamic charts.

Available visualizations:

- Revenue trends over time
- Expenditure trends
- Revenue vs expenditure comparison
- State-level financial comparison
- Tax revenue analysis
- Debt trends
- Expenditure distribution
- Correlation analysis


## 4. Revenue Forecasting

A machine learning forecasting module predicts future revenue trends.

Technology:

- Scikit-Learn
- Linear Regression

The model:

- Aggregates historical financial data
- Learns yearly revenue patterns
- Generates future revenue predictions


## 5. AI Financial Assistant

Integrated with Google Gemini AI.

Users can ask questions such as:

- "Summarize the financial condition."
- "What are the major trends?"
- "Which areas require attention?"
- "Provide financial recommendations."

The AI assistant analyzes the uploaded dataset and generates professional financial explanations.
